# روزنگار

نسخه مستقل و فارسی برنامه‌ریز روزانه برای دانش‌آموزان و کاربران عمومی.

## انتشار رایگان در GitHub Pages

1. یک مخزن جدید در GitHub بسازید.
2. تمام فایل‌های همین پوشه را در ریشه مخزن آپلود کنید.
3. وارد Settings و سپس Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. شاخه main و پوشه /(root) را انتخاب و Save کنید.

پس از چند دقیقه، نشانی برنامه در همان صفحه نمایش داده می‌شود. اطلاعات کاربران روی دستگاه خودشان ذخیره می‌شود و برنامه به سرور یا کارت بانکی نیاز ندارد.

## پرونده‌های روزانه و پروفایل‌ها

هر کاربر ابتدا یک پروفایل محلی می‌سازد. برنامه‌ها، تکالیف، عادت‌ها و یادداشت‌های هر روز در پرونده همان تاریخ ذخیره می‌شوند. روزهای دارای پرونده در تقویم مشخص‌اند و با کلیک روی هر روز می‌توان اطلاعات آن را دوباره مشاهده کرد.

پروفایل‌ها و پرونده‌ها فقط در همان مرورگر و دستگاه نگهداری می‌شوند. پاک‌کردن داده‌های مرورگر باعث حذف اطلاعات می‌شود و انتقال خودکار اطلاعات میان دستگاه‌ها در این نسخه وجود ندارد.

## زبان‌ها

انتخاب زبان برای فارسی، انگلیسی، ترکی، عربی، فرانسوی، آلمانی، اسپانیایی، ایتالیایی، پرتغالی، روسی، چینی، ژاپنی، کره‌ای و هندی فراهم شده است. زبان تقویم و متن آماده ایمیل‌های تماس، تبلیغات و خرید نیز با انتخاب کاربر هماهنگ می‌شود.
