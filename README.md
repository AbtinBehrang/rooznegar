# روزنگار

نسخه مستقل و فارسی برنامه‌ریز روزانه برای دانش‌آموزان و کاربران عمومی.

## انتشار رایگان در GitHub Pages

1. یک مخزن جدید در GitHub بسازید.
2. تمام فایل‌های همین پوشه را در ریشه مخزن آپلود کنید.
3. وارد Settings و سپس Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. شاخه main و پوشه /(root) را انتخاب و Save کنید.

پس از چند دقیقه، نشانی برنامه در همان صفحه نمایش داده می‌شود. اطلاعات کاربران روی دستگاه خودشان ذخیره می‌شود و برنامه به سرور یا کارت بانکی نیاز ندارد.
